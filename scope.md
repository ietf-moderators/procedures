# Scope of the moderation procedures

This file lists which forums are in and out of scope for the [moderation procedures](procedures.md).
The moderator team keeps it up to date. Where a forum is not listed, ask the moderator team.

## In scope

- All public mailing lists `@ietf.org`, except those listed as out of scope below
- Zulip chat streams and meeting chat for IETF working groups and other IETF sessions
- GitHub repositories, wikis, and issue trackers used by IETF working groups

## Out of scope

These belong to bodies that have not yet agreed to adopt the procedures (RFC9945, Section 1).

| Forum | Body |
|---|---|
| architecture-discuss@ietf.org | IAB |
| All lists `@iab.org` | IAB |
| All lists `@irtf.org`, and IRTF research group chat and repositories | IRTF |
| All lists `@rfc-editor.org` | RSWG, RSAB, and the Independent Submission Stream |

Non-public lists are not moderated by the moderator team, but their administrators may choose to
adopt these procedures (RFC9945, Section 3.1).
